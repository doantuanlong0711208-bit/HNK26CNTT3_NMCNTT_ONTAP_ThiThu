# Dự án Văn Phòng Phẩm Website

Dự án phát triển **website cửa hàng văn phòng phẩm** nhằm quản lý sản phẩm, đơn bán và *chuẩn hóa hệ thống dữ liệu*.

## Lập bảng

| Thư mục | Nội dung |
| :--- | :--- |
| `docs` | Chứa các tài liệu hướng dẫn và ghi chép nhập hàng |
| `media` | Chứa tài nguyên hình ảnh, logo của dự án |
| `data` | Chứa bảng tính Excel theo dõi đơn hàng và sản phẩm |
| `logs` | Chứa file log hệ thống và các báo cáo lỗi |
| `backup` | Chứa file lưu trữ dự phòng |

## Kiểm tra cấu trúc dự án

```Powershell
Get-ChildItem -Recurse
```
